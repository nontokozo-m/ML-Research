# Machine Learning Research: Gold Recovery Prediction

This project is a beginner-friendly machine learning research assignment completed as part of the BrightLearn programme. It explores machine learning concepts and demonstrates how Multiple Linear Regression can be used to predict gold recovery.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Databricks

## What I Did
- Researched supervised and unsupervised learning, regression, classification and model evaluation.
- Explored and cleaned a small synthetic gold-processing dataset.
- Prepared data using feed grade, pH, cyanide dosage and ore type.
- Split the dataset into training and testing sets.
- Trained a Multiple Linear Regression model.
- Evaluated predictions and analysed feature importance.

## Model Results

| Metric | Result |
|---|---|
| Mean Absolute Error (MAE) | 1.67 percentage points |
| Root Mean Squared Error (RMSE) | 1.96 percentage points |
| R² Score | 0.874 |

## Important Note

**This project is for educational purposes only.** It uses a small synthetic dataset rather than actual gold-processing plant data. The model and its predictions are intended for learning and practising machine learning techniques, not real-world application or operational decision-making.
